
# KM 双电机夹爪控制模块（C++版）

版本：1.0  
类型：独立夹爪控制  
范围：仅限夹爪控制（不包括机械臂控制）

---

## 1. 概述

该模块通过**TJFX 机械臂透传** 控制双电机并联夹爪（DM4310 电机）。程序使用 **MIT 模式** 控制夹爪，启动后夹爪会进行正弦波轨迹的往复运动。

此模块支持：
- 电机初始化
- MIT 位置控制
- 实时反馈读取
- 实时绘图（指令与反馈）
- 安全关闭处理

---


```bash

```

运行后，程序将启动夹爪并开始执行正弦波轨迹。

---

## 5. 控制逻辑

程序使用 **MIT 控制模式** 来控制夹爪。每次运行时，夹爪都会执行往复运动，控制逻辑如下：

```cpp
dm.control_mit(M1, 2.0, 0.15, q * 1.0 + 1.0, 0, 0);
```

参数说明：

* `M1`: 控制的电机
* `2.0`: 位置刚度（Kp）
* `0.15`: 速度阻尼（Kd）
* `q`: 目标位置
* `0`: 速度目标
* `0`: 当前目标

## 7. 实时反馈与绘图

程序提供实时反馈，通过以下方式查看夹爪控制状态：

```cpp
std::cout << "motor1--- POS:" << M1.Get_Position() << " VEL:" << M1.Get_Velocity() << " CUR:" << M1.Get_tau() << std::endl;
std::cout << "motor2--- POS:" << M2.Get_Position() << " VEL:" << M2.Get_Velocity() << " CUR:" << M2.Get_tau() << std::endl;
```

此外，程序支持实时绘图，通过 **matplotlib** 库显示电机的指令与反馈信息（命令与反馈位置、速度、力矩）。

## 10. 故障排除

### 1. 无法识别 USB 转 CANFD 设备

请检查：

* 设备是否正确连接
* udev 权限是否已正确配置
* `Serial Number` 是否填写正确

### 2. 电机没有响应

请检查：

* 电机波特率是否设置为 **5M**
* CAN ID 和 Master ID 是否设置正确
* 电机供电是否正常
* 接线是否正确

### 3. 程序报导入错误

如果出现类似错误：

```bash
ModuleNotFoundError: No module named 'src'
```

请检查是否在正确目录下运行程序，并确认 `src` 目录存在。

### 4. 电机反馈异常或运动不稳定

请检查：

* 是否正确连接终端电阻
* 是否存在多个设备 ID 冲突
* 波特率配置是否一致
* USB 通信是否稳定
